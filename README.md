# Indonesia Today — Portal Berita Statis

Halaman portal berita satu halaman dengan bagian *trending*, berita utama, berita
terkait, dan slot iklan. Dibuat untuk latihan **layout HTML/CSS** pada mata kuliah
Pemrograman Web.

## Teknologi
HTML5 · CSS3 · JavaScript (vanilla)

## Cara menjalankan
Buka `index.html` di browser.

## Struktur
```
├── index.html
├── styles.css
├── script.js
└── image/        # gambar berita, logo, dan iklan
```
